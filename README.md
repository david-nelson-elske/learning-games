# Learning games

Short videos and small games for children learning about the world, shared freely. Each subject has its own folder, and each lesson inside it is numbered in the order to watch or play.

## Maths

| # | Lesson | What it teaches | Length |
| --- | --- | --- | --- |
| 1 | [Counting tanks](maths/01-counting-tanks/) | Counting to ten, one object one number, adding groups, the plus and equals signs, swapping the order of a sum | 2:32 video |
| 2 | [Tank quiz](maths/02-tank-quiz/) | Three quick questions with time to think: 2 + 1, 4 − 1, 3 + 3 | 0:55 video |
| 3 | [Tank Maths](maths/03-tank-maths-game/) | A game: build, blow up and drag tanks between two sides to see adding, taking away and equal sides | Play in a browser |

## How to use it

- **Videos:** follow the video link in a lesson's README to watch or download it. Videos are kept out of git, so they are not in the lesson folders; see [docs/media.md](docs/media.md).
- **Games:** download the lesson folder and open `index.html` in a web browser. It works on a computer, tablet or phone, and needs an internet connection the first time, for its fonts and the three.js library.
