# Maths

Lessons in order. The first three use battle tanks as the things being counted, because tanks are more fun to count than apples. Lesson 4 is the same game with mermaids; the [game factory](../factory/) can make it with other things too.

1. [Counting tanks](01-counting-tanks/): counting to ten, and adding.
2. [Tank quiz](02-tank-quiz/): three quick questions.
3. [Tank Maths](03-tank-maths-game/): a game for building sums by hand.
4. [Mermaid Maths](04-mermaid-maths-game/): the same game with mermaids in two pools.

A good order: watch 1, then 2, then play 3 or 4 together. The quiz ends by inviting the child to play the game.
