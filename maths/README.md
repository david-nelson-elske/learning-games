# Maths

Lessons in order. Each uses battle tanks as the things being counted, because tanks are more fun to count than apples.

1. [Counting tanks](01-counting-tanks/): counting to ten, and adding.
2. [Tank quiz](02-tank-quiz/): three quick questions.
3. [Tank Maths](03-tank-maths-game/): a game for building sums by hand.

A good order: watch 1, then 2, then play 3 together. The quiz ends by inviting the child to play the game.
