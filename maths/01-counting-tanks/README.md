# Counting tanks

[counting-tanks.mp4](https://github.com/david-nelson-elske/learning-games/releases/download/media-v1/counting-tanks.mp4), 2 minutes 32 seconds.

**What it teaches**
- Counting from one to ten, one tank at a time.
- The two rules of counting: every object gets exactly one number, and the last number said is how many there are.
- Adding as putting groups together: 2 + 3 = 5, 4 + 4 = 8, 5 + 5 = 10.
- The plus sign means "put together", the equals sign means "the same amount".
- Swapping the groups keeps the answer: 3 + 2 = 2 + 3.

**To talk about after watching:** count real things together, then ask what happens if you swap two groups around.
